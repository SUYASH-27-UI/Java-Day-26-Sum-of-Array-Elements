# Java Day 26 - Sum of Array Elements

This Java program calculates the sum of all elements in an integer array using a `for` loop.

## Example

Array:
```text
10, 20, 30, 40, 50
```

Output:
```text
Sum of array elements = 150
```

## Concepts Used

- Arrays
- Array indexing
- `for` loop
- `numbers.length`
- Addition
- Variables

## How It Works

The program stores five numbers in an array. The `for` loop visits each element and adds it to the `sum` variable. After the loop finishes, the total sum is displayed.

## What I Learned

I learned how to access array elements using a loop and calculate their sum in Java.
